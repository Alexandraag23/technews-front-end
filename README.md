# TechNews

TechNews es una aplicación Front-end enfocada en la publicación
y consulta de noticias relacionadas con tecnología, innovación,
inteligencia artificial, desarrollo web y ciberseguridad.

## Objetivo

Desarrollar una plataforma web que permita consultar diferentes
noticias tecnológicas mediante una interfaz sencilla, moderna
e intuitiva.

## Funcionalidades

- Visualización de noticias tecnológicas.
- Carga dinámica de noticias desde JSON.
- Vista detallada de las noticias.
- Gestión de noticias favoritas.
- Almacenamiento de favoritos mediante localStorage.
- Formulario de contacto con validaciones.
- Gestión básica para agregar y eliminar noticias.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- localStorage

## Estructura del proyecto

El proyecto está organizado en diferentes archivos y carpetas
para separar la estructura HTML, estilos CSS, lógica JavaScript,
datos JSON e imágenes.
